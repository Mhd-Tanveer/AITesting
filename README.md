# AI Testing Blueprint 3x

This repository is a practical learning workspace for AI-assisted testing, prompt engineering, retrieval-augmented generation (RAG), browser automation, and QA-focused demos.

It brings together multiple mini-projects that demonstrate how AI and modern automation tools can be applied in software testing and product development workflows.

## What is included?

This repository contains hands-on projects for:
- LLM fundamentals and concept exploration
- RAG application development
- Test case generation and test planning
- Selenium-based automation frameworks
- Workflow automation examples
- Reusable QA and prompt templates

## Repository structure

| Area | Purpose |
|---|---|
| [BasicRAG_Tanveer](BasicRAG_Tanveer) | A React + Flask RAG demo that ingests PDFs, creates chunks, stores embeddings, and answers questions using an LLM. |
| [chapter_01_LLM_Basics](chapter_01_LLM_Basics) | Notes and learning materials for understanding LLM basics and transformer concepts. |
| [chatpter_03_n8n_Agents](chatpter_03_n8n_Agents) | Example workflow/agent artifacts for automation and agent-based scenarios. |
| [Job_Tracker_AI](Job_Tracker_AI) | A Kanban-style job application tracker built with React and local persistence. |
| [Project1_TC_Gen](Project1_TC_Gen) | Test case generation and QA documentation examples, including API test cases and JIRA-style formats. |
| [Project2_Selenium_Framework](Project2_Selenium_Framework) | Selenium automation framework starter project with page object model structure and example tests. |
| [templates](templates) | Reusable prompts and templates for test case creation, API testing, regression, and security testing. |
| [Anti_Hallucinations_Rules.md](Anti_Hallucinations_Rules.md) | A guide for grounding AI responses in verified facts and reducing hallucinations. |

## Project highlights

### 1. BasicRAG_Tanveer
A beginner-friendly RAG implementation that demonstrates:
- PDF ingestion
- Text chunking
- Embedding generation
- ChromaDB-based vector storage
- Retrieval and answer generation using an LLM

### 2. chapter_01_LLM_Basics
A starting point for understanding:
- LLM basics
- Attention and transformer concepts
- The role of prompts in AI workflows

### 3. Project1_TC_Gen
Focused on QA and test planning, including:
- API test cases
- Execution guides
- JIRA-style documentation templates

### 4. Project2_Selenium_Framework
A Selenium automation starter project covering:
- Framework structure
- Page object model concepts
- Sample automation test design

### 5. Job_Tracker_AI
A local-first React application for tracking job applications with:
- Kanban workflow
- Search and filter support
- Persistent local data storage

## Suggested learning path

1. Start with [chapter_01_LLM_Basics](chapter_01_LLM_Basics) for the foundations.
2. Explore [BasicRAG_Tanveer](BasicRAG_Tanveer) to see a working RAG flow.
3. Review [Project1_TC_Gen](Project1_TC_Gen) for AI-assisted QA and test case generation ideas.
4. Try [Project2_Selenium_Framework](Project2_Selenium_Framework) for automation practice.
5. Use [Job_Tracker_AI](Job_Tracker_AI) and [templates](templates) for practical app and prompt examples.
